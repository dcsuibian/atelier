# 前端构建与依赖

适用于 `atelier-ui`。

- 一律显式 import，不用自动导入插件。插件在编译时注入的 import，Vite 的依赖预构建扫描不到，开发时会反复整页刷新；它生成的类型文件也要先构建一次才有。
- Element Plus 样式全量引入，这样自定义的主题变量才生效，体积只多几 KB。ECharts 按模块引入，它全量太大。
- 只用 Prettier 统一格式，不用 ESLint、git hook、提交信息校验这类工具。这是作者的个人喜好。
- 浏览器原生能做的，不加依赖。
- 哈希用纯 JS 实现，不用 Web Crypto。Web Crypto 只在 HTTPS 或 localhost 下可用，局域网 IP 走 http 访问时用不了。
